# Hearth & Honey bakery

Original fictional bakery website. No external assets or dependencies. Run npm test for automated checks. Serve this folder with any static HTTP server; ES modules need HTTP rather than opening index.html directly.

Responsive navigation, category filters, demo basket and integer-cent totals. No orders, payment processor, analytics, external messages or real storefront are connected.
